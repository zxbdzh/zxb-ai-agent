---
title: 演进记录
description: 由学习检查点生成并经审查的不可变历史记录。
docType: evolution-index
---

演进记录只对应带完整 `Learning-*` trailer 的学习检查点，不覆盖每个提交。文件名为 `<yyyy-mm-dd>-<短SHA>-<slug>.md`，正文保留作者逐字提供的学习动机与学习结果，并用仓库或受控外部来源支持事实。

现有记录不得改写解释。事实错误只能追加带作者和日期的“事实修订说明”；理解发生变化时，应创建新的学习检查点和演进记录。

当前没有经该流程生成并审查的演进记录。已知历史提交只列在[历史清单](../reference/historical-checkpoints/)，清单不推断动机或结果。

## 从这里重新进入项目

### 当前能力

先完成环境、模型和运行配置，再查看对话记忆与会话隔离。当前指南只描述代码现在能够证明的行为。[从环境与安装开始](./current/setup/)。

### 演进证据

学习检查点按完整提交 SHA 保存动机、结论、引用和验证 evidence。普通提交不会制造文档噪声。[查看演进记录](./evolution/)。

### 自动化边界

搜索、结构化生成、人工审查和 Pages 发布各自有明确权限。模型不执行网页或自身建议的命令。[阅读自动化安全边界](./automation/security-and-providers/)。

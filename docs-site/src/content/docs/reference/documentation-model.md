## 词汇

- **未来维护者**：实现背景已经淡化后返回项目的所有者，是本站主要读者。
- **运维指南**：描述当前运行、配置、验证和排障方式的主题文档。
- **当前指南**：持续维护的当前操作说明；本项目固定为五个受验证路由。
- **学习检查点**：作者主动选择、由完整 trailer 标记、值得形成演进记录的代码提交。普通提交和文档提交不是检查点。
- **学习动机**：检查点作者提供的问题或维护需要。自动化必须逐字保存，不能从 diff 推断。
- **学习结果**：检查点作者提供的权威结论。自动化可补充证据，但不能发明。
- **演进记录**：按检查点 SHA 唯一标识的历史说明。
- **文档拉取请求**：自动化针对检查点提出、供人工审查的演进记录和最小当前指南更新。

## 贡献规则

当前指南的项目事实必须列出证据路径、完整 `verifiedAgainst` SHA、核验日期和命令。证据路径自该 SHA 到 `HEAD` 有变化时，本页即过期，必须人工复核并重新盖章。

演进记录一经审查落地，其解释不可原地重写。事实错误仅追加署名、日期、原因和证据齐全的修订说明；新解释必须来自后续学习检查点。

Markdown 保持可移植：使用 `.md`、GFM 表格和 fenced code；不用 import、JSX、原始 HTML、Astro/Starlight 指令、工具专属标题属性或站点绝对链接。跨页链接指向相对 `.md` 文件，并避免依赖中文标题 fragment。

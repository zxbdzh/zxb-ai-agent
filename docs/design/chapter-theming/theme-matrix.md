# 章节主题矩阵（Theme Matrix）

本表是章节感知型主题系统的唯一事实来源，与 `docs-site/src/styles/chapter-theme.css` 第 1 节一一对应。

## 矩阵

| 章节 | data-chapter | 色相 H | 暗色 S/L | 亮色 accent（对比度校准） | 情绪关键词 | 签名动效 | 触发时机 | 进入方向（过渡） |
|---|---|---|---|---|---|---|---|---|
| 首页 | `home` | 224 | 100% / 60% | `hsl(224 90% 55%)` ≈ 5.8:1 | 品牌锚点、可信、启动 | Hero 标题渐变描边 | 页面加载 | 居中浮现 |
| 当前指南 | `current` | 160 | 84% / 60% | `hsl(160 92% 26%)` ≈ 4.8:1 | 轻盈、向上、启动感 | 标题描边 + 卡片悬停浮起 | 加载 + 悬停 | 自下而上（向上箭头语义） |
| 演进记录 | `evolution` | 265 | 82% / 60% | `hsl(265 78% 52%)` ≈ 5.5:1 | 深度、沉淀、编年史 | 状态灯指示灯 + 粒子聚合（L3） | 加载 + 视口 | 自左滑入（时间回溯语义） |
| 参考资料 | `reference` | 215 | 64% / 60% | `hsl(215 72% 40%)` ≈ 5.0:1 | 精确、克制、机械感 | 数据网格微动 + 数据流（L3） | 悬停 + 视口 | 自右滑入（检索语义） |
| 自动化维护 | `automation` | 35 | 92% / 60% | `hsl(35 92% 32%)` ≈ 5.4:1 | 关注、警示、工程感 | 警示图标脉冲 | 加载（循环） | 自上滑入（下发语义） |

衍生色规则（全部由 HSL 公式从 `--chapter-hue` / `--chapter-sat` 派生，见 design-tokens.md）：

- 渐变副色 = hue + 40°（暗色）/ 相对色语法（亮色）
- 辉光 = 主色 60% 明度、alpha 0.16-0.18
- 代码块边框 = 主色 45% 饱和、alpha 0.6-0.7；代码背景 = 主色 18% 混入 EC 底色

## 动效强度分级

| 等级 | 名称 | 覆盖范围 | 实现 |
|---|---|---|---|
| L0 | 经典 | 无任何动画与氛围光；尽力跳过跨文档 View Transition | CSS 门控全关 + 根节点 `view-transition-name: none` |
| L1 | 标准（默认） | 全站氛围光（轻柔）、标题流光描边、侧边栏活跃辉光+指示灯、阅读进度条、导航发丝线、章节染色 | 纯 CSS |
| L2 | 丰富 | L1 + 氛围光增强 + 卡片/引用块/Callout/表格行 悬停与入场响应、代码块悬停增亮、自动化章节警示脉冲 | 纯 CSS |
| L3 | 沉浸 | L2 + 氛围光最强 + 首页 Hero 渐变流光标题 + 章节首页 Canvas 效果（按需分包 JS） | CSS + Canvas |

## 章节首页 Canvas 效果规格

| 章节 | 效果 | 粒子规模 | 帧率 | 触发 | 暂停条件 |
|---|---|---|---|---|---|
| evolution | 粒子聚合消散：四边弹簧汇聚到标题区，抵达后发光消散重生 | 60-200（按面积自适应） | 30fps | `data-motion=3` 且路径为 `/evolution/` | 离开视口 / 标签页隐藏 |

## 语义映射说明

站点真实分区（当前指南/演进记录/参考资料/自动化维护）与通用文档章节的对应关系：
快速开始 → 当前指南（启动感，青绿）；核心概念/版本史 → 演进记录（深度，蓝紫）；API/事实参考 → 参考资料（精确，冷靛银）；故障排查/运维 → 自动化维护（警示，琥珀橙）；门户 → 首页（品牌蓝锚点）。
